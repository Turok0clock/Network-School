NETWORK+ N10-009 PROFESSOR & LAB — V6
======================================

THIS BUILD IS DESIGNED AS A COMPLETE OFFLINE STUDY SYSTEM.

CORE AREAS
----------
1. Tracker
   - Correct source of truth: everything complete except 1.7 and Domain 5.
   - 4.2 is complete but pre-flagged for review.
   - Completion and Needs Review are separate.

2. Professor Desk
   - Objective-by-objective N10-009 teaching.
   - Exam lens, must-know concepts, and common traps.
   - Direct links to objective quizzes and related PBQ labs.

3. PBQ Lab Center
   - 20 dedicated practical labs OUTSIDE the full exams.
   - Guided mode: check each configuration choice and get teaching feedback.
   - Exam mode: no feedback until submission.
   - Lab debrief explains every field and tracks attempts/scores.

4. Focus Lab
   - Uses a SEPARATE 50-question quiz bank so short drills do not spoil the full exams.
   - Immediate correct/incorrect feedback.
   - Correct answer, explanation, exam takeaway.
   - End-of-quiz question-by-question review.
   - Retry missed questions.

5. Flashcards
   - Confidence tracking: Again / Got it.
   - Revisit counts stored locally.

6. Full Exams
   - Three 90-question simulations.
   - 90-minute timer.
   - Blueprint-balanced domains.
   - PBQs included.
   - Full debrief can show misses only OR all 90 questions, including questions answered correctly.
   - Objective labels and teaching explanations.

7. Stats
   - Exam history.
   - Most-missed topics.
   - PBQ lab history.
   - Flashcard confidence.

IMPORTANT
---------
Simulator percentages are diagnostic. The real CompTIA exam uses scaled scoring.

GITHUB
------
Upload the CONTENTS of this folder to the ROOT of your GitHub repository:
index.html
manifest.webmanifest
sw.js
README.txt
icons/

Enable Pages: Settings -> Pages -> Deploy from a branch -> main -> /(root)

When replacing an older version, the new service-worker cache name (v6) forces browsers to retrieve the new application files. If the iPad still shows an old build, close/reopen the Home Screen app while online or remove/re-add it after GitHub Pages finishes deploying.
